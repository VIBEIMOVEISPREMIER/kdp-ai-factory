# Security Policy

## Never commit

- Bybit API keys or secrets
- License signing private keys
- Production database credentials
- Production environment files
- Customer payment information

## Official payment address

The public receiving address is documented in the official configuration. The signing key and exchange credentials remain server-side only.

## Reporting

Do not publish credentials or exploit details in an issue. Report sensitive security problems privately to the project owner.

## Important limitation

Open-source software can be modified by third parties. The official trust boundary is the official release plus the remote licensing service.

# Modelos de IA

O Factory foi desenhado para usar modelos locais.

## Texto
O primeiro adaptador é o Ollama. O Factory consulta os modelos instalados localmente e não exige uma API paga.

## Imagens
ComfyUI será o primeiro motor de imagem. Workflows ficam isolados do núcleo para permitir diferentes modelos e pipelines.

## Princípio
Não existe limite artificial de créditos dentro do Factory. O limite prático é o hardware disponível: VRAM, RAM, armazenamento, energia e tempo de processamento.

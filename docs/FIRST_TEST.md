# Primeiro teste

1. PowerShell na raiz do projeto.
2. Execute `Set-ExecutionPolicy -Scope Process Bypass` se o Windows bloquear scripts.
3. Execute `.scriptsirst-test.ps1`.
4. Inicie a API com `.scriptsstart.ps1`.
5. Em outro terminal, inicie o dashboard com `.scriptsstart-dashboard.ps1`.
6. Abra o endereço mostrado pelo Vite.
7. Crie um projeto.
8. Acesse o workspace.
9. Confirme projetos e pipeline.
10. Para testar IA local, instale/inicie Ollama e tenha pelo menos um modelo instalado; use o Assistente local.
11. Para testar imagens, configure ComfyUI e use um workflow exportado no formato API.
12. Para testar exportação, use a API/CLI com um manuscrito salvo.

O Factory não baixa modelos pesados automaticamente.

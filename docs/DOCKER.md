# Docker legacy mode

Docker is no longer the recommended local installation path for KDP AI Factory.

## Recommended Windows path

Use the native installation documented in [INSTALL_WINDOWS.md](INSTALL_WINDOWS.md).

This avoids requiring Docker Desktop or WSL2 on the user's Windows machine.

## Cloud

The official licensing service has a separate deployment definition for Render in `render.yaml`.

The old Docker files are retained as legacy developer infrastructure and are not required for normal use.

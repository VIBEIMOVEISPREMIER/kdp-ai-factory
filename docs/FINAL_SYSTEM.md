# KDP AI Factory — sistema 1.0

## Entregue
- Projetos persistentes, manifest, especificação e checkpoints.
- Pipeline editorial modular.
- Ollama para texto local.
- ComfyUI para imagens por workflow JSON.
- Importação de PDF, DOCX, TXT, MD, EPUB, CSV, PPTX, imagens e áudio como fonte.
- Estrutura, escrita, revisão e tradução com IA local.
- Motor PDF inicial e formatos de livro.
- Cálculo de capa/lombada separado do validador.
- Validação de especificação e PDF.
- Catálogo de assets.
- Metadados exportáveis.
- CLI e API sobre o mesmo núcleo.
- Dashboard visual.
- Arquitetura multilíngue e extensível.

## Fluxo
Criar → configurar → importar → estruturar → escrever → revisar/traduzir → ilustrar → diagramar → capa → validar → exportar → revisar no KDP → publicar.

## Limites
Não há API paga obrigatória. A qualidade e velocidade dependem do hardware/modelos locais. A publicação Amazon KDP fica isolada para não fingir que existe uma API oficial de publicação completa nem armazenar credenciais.

## Extensões previstas
OCR local, transcrição local, exportadores EPUB/DOCX avançados, editor WYSIWYG, workflows ComfyUI por gênero, desktop e E2E.

# Book Engine

Fluxo editorial:
Briefing → estrutura → manuscrito → revisão → recursos → layout → capa → validação → exportação.

Tipos suportados pela arquitetura incluem infantil, ficção, educativo, workbook, journal, receitas, estudo, poesia, notebook, coloring e personalizado.

Novos tipos devem ser adicionados por templates, não por lógica espalhada pela aplicação.
